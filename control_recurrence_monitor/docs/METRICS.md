# Metrics

| Metric | Definition | Guardrail |
|---|---|---|
| Recurrence rate | Exits with a later failed target / monitored exits | Never hide snapshot gaps |
| Time to recurrence | Days from verified exit to first failed snapshot | Detection time is not failure start time |
| Cadence compliance | Surveillance with no excessive snapshot gap / surveillance | Cadence is declared policy |
| Remediation durability | Snapshots retaining completed remediation / snapshots | Completion evidence still needs review |
