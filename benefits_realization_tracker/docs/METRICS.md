# Product metrics

| Metric | Definition | Guardrail |
|---|---|---|
| Measurement coverage | Benefits with an observed value / all benefits | Never equate coverage with realization |
| Realization rate | Benefits at or beyond target / measured benefits | Segment by unit and target horizon |
| Overdue review rate | Unmeasured benefits past target date / all benefits | Keep owners visible |
| Evidence-linked coverage | Benefits retaining one or more evidence IDs / all benefits | Zero-link records should be rejected upstream |
| Time to measurement | Days from baseline to observation | Do not reward premature measurement |
| Attribution review coverage | Benefits with a reviewed attribution note / all benefits | Notes do not prove causality |

Do not publish a single monetary “total value” unless a separate reviewed model converts each measure using explicit, auditable assumptions.
