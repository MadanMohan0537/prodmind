# Product metrics

| Metric | Definition | Initial target |
| --- | --- | --- |
| Evidence-complete review rate | Reviews containing delivery and analysis evidence / reviews | 100% |
| Premature-adoption prevention | Adopt decisions blocked before timing, sample, or guardrail requirements pass | 100% |
| Decision traceability | Outcomes linked to Project 32 experiment and prior outcome IDs | 100% |
| Verification latency | Time from complete input to deterministic report | p95 under 250 ms at documented limits |
| Human-decision coverage | Reviews with named reviewer, decision, and rationale | 100% |

These are operating targets, not claims established by the repository tests.
