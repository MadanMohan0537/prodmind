# Metrics

| Metric | Definition | Guardrail |
|---|---|---|
| Verified closure rate | Passing close reviews / close attempts | Never reward short observation windows |
| Failed effectiveness tests | Failed tests across reviews | Preserve evidence and criterion |
| Reopened-target rate | Targets failing after verified closure | Treat as learning, not blame |
| Median days to verified exit | Request to passing review | Segment by risk and complexity |
| Remediation completeness | Reviews with completed evidenced obligation / reviews | Completion is not effectiveness by itself |
