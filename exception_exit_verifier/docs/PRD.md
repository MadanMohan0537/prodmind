# Product requirements

Project 27 prevents exception closure from becoming a paperwork exercise. It compares the active Project 26 exception with a later Project 25 monitor, verifies the original target and remediation obligation are resolved, requires evidenced effectiveness tests and a completed observation window, and records an independent close, extend, or escalate decision.

It preserves governance-pack, portfolio-item, and customer-evidence lineage. It does not execute remediation, mutate monitors, close exceptions, or guarantee that a control will remain effective.
