# Architecture

Project 7 reconstructs Projects 18–21 before invoking this stateless engine. `planId` joins each snapshot to authoritative adoption and lifecycle lineage. Caller-supplied snapshot data can report execution evidence but cannot replace upstream identifiers or plan requirements.

The engine validates bounded aggregate cohorts, exact count reconciliation, dependency-set coverage, notice status, exception status, telemetry, shutdown checks, and named approvals. It returns deterministic checks and never calls an operational system.

## Trust boundaries

- The HTTP surface uses bearer authentication, no-store responses, restrictive browser headers, and a 2 MB body limit. Project 7 also rejects cross-origin API requests.
- Receipts and evidence strings are not cryptographically verified.
- Aggregate cohorts reduce unnecessary identity exposure but do not replace organizational privacy controls.
- No endpoint performs the sunset.
