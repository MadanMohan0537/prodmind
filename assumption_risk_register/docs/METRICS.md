# Metrics

| Metric | Definition | Guardrail |
|---|---|---|
| Assumption coverage | Selected items with at least one registered assumption / selected items | More assumptions are not automatically better |
| Unlinked rate | Assumptions without evidence or experiment links / assumptions | A link does not prove validity |
| Validation throughput | Assumptions moved from testing to supported/refuted per period | Never reward predetermined outcomes |
| Overdue rate | Unresolved assumptions past review date / unresolved assumptions | Preserve owner visibility |
| Refutation lead time | Days from registration to refutation | Fast is useful only when the test is credible |
| Category balance | Distribution across five assumption categories | Not every item requires equal category counts |
