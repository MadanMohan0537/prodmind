# Product metrics

| Metric | Definition | Guardrail |
|---|---|---|
| Promotion evidence completeness | Passed required checks / 13 | Completeness is not correctness |
| Stabilization coverage | Hours from Project 52 review to final checkpoint | Require declared minimum and gap limit |
| Reference-class coverage | Classes meeting sample and paired-error gates / scope | Never hide a failing class in an average |
| Control health | Healthy required controls / reported controls | Any failed control blocks promotion |
| Decision latency | Final review time − Project 52 review time | Do not optimize below the observation window |
| Post-promotion reversal rate | Promotions later rolled back / promotions | Track downstream; do not infer causality |
