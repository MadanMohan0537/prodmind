# Architecture

The pure deterministic engine accepts immutable Project 51 learning, Project 52 assurance, and a promotion assessment. It validates bounded input, reconstructs lineage, aggregates reference-class evidence, evaluates thirteen explicit controls, and returns a recommendation plus a named human decision.

The Worker provides a same-origin, bearer-authenticated JSON endpoint and static light/dark interface. Secrets are supplied through `wrangler secret`; no secret is committed or returned. Project 7 reconstructs Projects 40–52 server-side before invoking the engine.

Promotion is intentionally external. The project does not activate versions, edit estimates or factors, expand exposure, remove rollback, or prove that the candidate caused an observed improvement.
