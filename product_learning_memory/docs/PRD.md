# Product requirements

## Problem

ProdMind can collect evidence, rank opportunities, run experiments, record decisions and monitor outcomes. Without cross-run retrieval, those learnings remain trapped inside individual workflows and teams can repeat experiments or make decisions without reviewing prior evidence.

## User outcome

Before planning an opportunity, a PM can search plain language and retrieve prior decisions with their hypotheses, metrics, evidence records and latest monitored outcome.

## MVP requirements

- Index decided experiments from up to 50 bounded ProdMind runs.
- Preserve run, opportunity, experiment, decision and evidence identities.
- Show the original evidence excerpts rather than generated claims.
- Filter by ship/iterate/reject and monitored status.
- Explain which fields and terms produced each match.
- Never automatically reuse an old decision or change a current priority.

## Non-goals

Semantic embeddings, causal meta-analysis, autonomous recommendations, cross-tenant search and automatic roadmap mutation are outside this zero-cost MVP.
