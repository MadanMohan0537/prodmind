# Product metrics

- Search success: searches that return at least one reviewed prior decision.
- Evidence traceability: returned cards whose evidence IDs resolve to source records (target 100%).
- Monitoring coverage: decisions with at least one Project 8 outcome review.
- Learning reuse: opportunities where prior learning was opened before experiment planning.
- Contradiction review rate: conflicting historical decisions that receive explicit PM review (future capability).

Retrieval relevance is not proof that an old decision applies to a new context. Teams should inspect dates, segments, evidence and monitoring status.
