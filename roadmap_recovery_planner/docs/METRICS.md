# Product metrics

- **Failed-control coverage:** unique severity-weighted Project 41 failures addressed by selected actions divided by all failed-control weight.
- **Capacity utilization:** selected recovery effort divided by declared recovery capacity.
- **Baseline-change rate:** selected actions requiring formal baseline decisions divided by selected actions.
- **Reversible-action rate:** reversible selected actions divided by selected actions.
- **Action acceptance rate:** approved scenarios divided by reviewed scenarios.
- **Evidence completeness:** selected actions retaining planning evidence, exit criteria, ownership, affected work, and original customer evidence.
- **Recovery follow-through:** approved actions later supported by completion and exit evidence. This requires future observations and is not inferred by Project 42.

Metrics must not reward automatic approval, hidden rebaselining, or unsupported causal claims.
