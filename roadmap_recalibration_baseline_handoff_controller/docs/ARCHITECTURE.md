# Architecture

The deterministic engine accepts an immutable Project 54 outcome and a proposed baseline handoff. It validates the manifest, exact reference-class coverage, acknowledgments from the scheduler and four estimation controls, superseded-version archive, rollback, monitoring ownership, approvals, and final review.

The Worker exposes a bearer-authenticated same-origin endpoint and responsive light/dark interface. Project 7 reconstructs Projects 40–54 before invoking the controller. The standalone project requires no database, hosted model, or paid API.

The result is a control record, not a configuration transaction. Every downstream system remains externally owned.
