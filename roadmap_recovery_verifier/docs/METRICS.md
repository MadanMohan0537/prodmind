# Product metrics

- **Action completion rate:** completed selected actions divided by selected actions.
- **On-time completion rate:** on-time selected actions divided by selected actions.
- **Effort exception rate:** actions exceeding the declared tolerance divided by selected actions.
- **Control restoration rate:** originally failed controls now passing divided by originally failed controls.
- **Observation maturity:** days between latest action completion and follow-up control evidence.
- **Verified close rate:** verified recovery records divided by close decisions.
- **Evidence completeness:** outcomes retaining execution, exit, source-report, work-item, and customer-evidence lineage.

These metrics must not reward unsupported closure or hidden baseline changes.
