# Architecture

The pure engine joins a selected Project 29 action to its covered recurrence targets, then verifies that later Project 28 surveillance has the same governance pack, portfolio item, and exception-exit identity. Checks compare delivery evidence, dates, effort, follow-up count, observation duration, and recurrence state.

The connected Project 7 route reconstructs Projects 18–29 server-side, independently builds the later Project 28 report, and only then calls Project 30. Client-supplied reports cannot replace authoritative lineage.

The Worker requires bearer authorization, rejects cross-origin API calls, caps JSON at 2 MB, disables caching, and serves static assets separately. The engine has no network or paid-model dependency.
