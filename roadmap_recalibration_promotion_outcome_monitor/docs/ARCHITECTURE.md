# Architecture

The pure engine accepts an immutable Project 53 report plus an externally executed promotion record and longitudinal snapshots. It validates authorization, reconstructs reference-class outcomes, evaluates thirteen controls, and returns a reviewable recommendation.

The Worker exposes a bearer-authenticated same-origin endpoint and a system-aware light/dark interface. Project 7 reconstructs Projects 40–53 server-side before invoking the outcome monitor. No database, hosted model, or paid API is required by the standalone project.

The output is evidence for the existing Projects 46–47 effectiveness and drift loop. It does not silently update their baseline, activate or revert a version, change estimates, or establish causality.
