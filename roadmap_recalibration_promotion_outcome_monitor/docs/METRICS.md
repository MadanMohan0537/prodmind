# Product metrics

| Metric | Definition | Guardrail |
|---|---|---|
| Activation fidelity | Exact authorized execution checks passed | Never infer execution from approval |
| Final adoption | Promoted population / scoped population | Preserve partial adoption explicitly |
| Observation coverage | Hours and maximum gap after activation | Require declared minimums |
| Reference-class reliability | Classes meeting sample, error, and improvement gates / scope | Never hide a failing class in an average |
| Control health | Healthy required controls / required controls | Any failed control blocks retention |
| Promotion reversal rate | Verified promotions later rolled back / verified promotions | Track downstream without causal claims |
